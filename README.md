# MCP Experiment

This repository is created as an experiment for working with the Model Context Protocol (MCP).

## About

This project demonstrates the capabilities of MCP servers and how they can be used to interact with various services, including GitHub.

## Features

- GitHub integration
- Automated repository management
- File operations

## Getting Started

To get started with this project:

```bash
git clone https://github.com/vivmagarwal/mcp-experiment.git
cd mcp-experiment
```
